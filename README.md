# WEB103 Project 1 - *Football Legends Listicle*

Submitted by: **David Enebeli**

About this web app: **Football Legends is a list-based web application that showcases some of the greatest football players in history. Users can browse player cards containing key information such as nationality, position, and playing era, then select a player to view a detailed page with additional information and career achievements.**

Time spent: **4** hours

## Notes

One challenge I encountered while building the app was connecting the frontend to the Express backend and separating the webpage routes from the API routes. I also learned how to use dynamic route parameters to create a unique detail page for each football legend. Building this project helped me better understand how the frontend and backend communicate using HTTP requests and JSON data.
